# ☕ Coffee Enthusiasts Club

A responsive, coffee-themed community website built using HTML5 and CSS3 as part of the Codecademy Front-End Engineer Career Path.

The website provides a welcoming space for coffee enthusiasts to learn about the club, explore upcoming activities, and discover how to join the community.

## Features

- **Responsive Design:** Layouts adapt to desktop, tablet, and mobile screen sizes.
- **Navigation:** Section-based navigation links for Home, About, Events, and Join.
- **Community Information:** Dedicated sections introducing the club and its activities.
- **Interactive Styling:** A styled Join Now button with hover effects and a 3D-inspired box shadow.
- **Consistent Visual Design:** Coffee-inspired colors, typography, and spacing.

## Technologies Used

- **HTML5** — Semantic page structure and content
- **CSS3** — Styling, typography, spacing, and visual effects
- **Flexbox** — Flexible navigation layout
- **Media Queries** — Responsive layouts for different screen sizes
- **Git & GitHub** — Version control and project hosting
- **Chrome DevTools** — Responsive testing and debugging

## Responsive Design

The website was tested using Chrome DevTools at the following viewport widths:

| Device | Viewport Width |
|--------|---------------|
| Mobile | 375px |
| Tablet | 768px |
| Desktop | 1440px |

## Getting Started

To run the project locally:

1. Clone the repository:

   `git clone git@github.com:Kbuck2290/coffee-enthusiasts-club.git`

2. Open the `coffee-enthusiasts-club` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No additional dependencies or installation steps are required.
